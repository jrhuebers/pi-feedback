# Changelog

## 0.1.0

- Add `/feedback [text]` for immediate capture or multiline editing without model calls.
- Add `/feedback-show [search text]` with Inbox, Planned, and Done columns, detail views, editing, status changes, search, and sorting.
- Store private Markdown notes and a generated board under the active Pi profile, with optional shared storage.
- Record minimal session/model provenance without copying transcripts or uploading data.
- Support vanilla Pi, pi-research profiles, narrow terminals, and RPC dialogs.
